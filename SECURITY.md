# Segurança e privacidade

Este repositório público não contém logs reais, endereços MAC, endereços IP ou histórico operacional da UFF.

- A demonstração usa exclusivamente dados sintéticos.
- A importação remove MAC e IP antes de persistir o histórico.
- `WIFI_HASH_SALT` deve ser configurado fora do Git e ter pelo menos 16 caracteres.
- Arquivos em `data/importar`, `data/historico`, `data/arquivados` e `data/rejeitados` são ignorados pelo Git.

Para comunicar uma vulnerabilidade, abra um contato privado com o responsável pelo projeto; não publique dados ou evidências sensíveis em issues.
